# Contributing

Thanks for your interest in Transmission Modern!

1. Open an issue describing the problem or proposed improvement.
2. Keep changes focused, and preserve compatibility with the existing Transmission RPC endpoint.
3. Test desktop and mobile portrait/landscape layouts, plus Minimal and Cards views.
4. Avoid committing credentials, private IPs, download data or personal torrent names.
5. Include before/after screenshots for visual changes (with private data redacted).

No build step is required. HTML, CSS and JavaScript are served directly by Transmission.
